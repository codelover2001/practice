SAGA Pattern (Orchestration)

Sequence of local transactions, each with a compensating action.
Step 1: Create order → Step 2: Charge payment → Step 3: Reserve stock → Step 4: Notify restaurant

If step 3 fails: compensate step 2 (refund) → compensate step 1 (cancel order).
No global locks. No 2PC blocking. Each step commits immediately. Undo on failure.
