Three-Phase Commit (3PC)

3PC adds a pre-commit phase between prepare and commit.
Phase 1: "Can you?" → Phase 2: "Everyone said yes, get ready" → Phase 3: "Commit!"

The fix: If coordinator crashes after pre-commit, participants KNOW everyone agreed → they commit independently. In 2PC they'd be stuck.
The weakness: Still breaks under network partitions (one side commits, other aborts).
